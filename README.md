# 🌍 About

**WasteWise** is a smart waste management web application designed to improve waste collection and encourage responsible waste disposal. Users can report waste locations, track complaint status, learn recycling practices, and contribute to building cleaner cities.

# ⚡ Getting Started

## Clone Repository

```bash
git clone https://github.com/Sourav-bhardwaj02/wastewise.git
```

## Navigate

```bash
cd WasteWise
```

## Install Dependencies

### Client

```bash
cd client
npm install
```

### Server

```bash
cd ../server
npm install
```

## Run Backend

```bash
npm start
```

## Run Frontend

```bash
cd ../client
npm run dev
```
